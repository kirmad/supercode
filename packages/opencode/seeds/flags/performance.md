# Performance Mode

Enable comprehensive performance monitoring, profiling, and benchmarking capabilities.

## Features Enabled

- Performance profiling (`--enable-profiling`)
- Memory monitoring (`--memory-monitoring`)
- CPU profiling (`--cpu-profiling`)
- Call tracing (`--trace-calls`)
- Benchmark mode (`--benchmark`)
- JSON output format for metrics (`--output-format json`)

## Best Used For

- Performance analysis
- Bottleneck identification
- Memory leak detection
- Optimization work
- Performance regression testing

## Example Usage

```bash
supercode --performance run complex-task.js
supercode --performance build --analyze-bundle
```

This flag enables detailed performance insights for optimization.
